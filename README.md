- Mark tasks as completed

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/Darrylwin/toDoApp.git
    ```
2. Navigate to the project directory:
    ```sh
    cd toDoApp
    ```
3. Install dependencies:
    ```sh
    flutter pub get
    ```
4. Run the app:
    ```sh
    flutter run
    ```
